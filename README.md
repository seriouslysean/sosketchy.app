# sosketchy.app

Landing page for [So Sketchy](https://sosketchy.app), an iMessage game.

Static Astro site on GitHub Pages. See `CLAUDE.md` for conventions.

## Run

```bash
nvm use
cp .env.example .env
npm install
npm run dev
```

## Pages

- `/` home
- `/privacy` privacy policy
- `/support` support
- `/robots.txt`, `/sitemap.xml` generated at build
